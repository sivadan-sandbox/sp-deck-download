# SP Deck（ダウンロード）

スマホを、PC の「ワンボタン操作盤」にするアプリです。
スマホのボタンを押すと、同じ Wi-Fi にいる PC のミュートや音量、再生／停止、仮想デスクトップの切り替えができます。電話がかかってきた時は、何も押さなくても、PC が自動でミュートになります。

個人が、試しに作ったものです。

## ダウンロード

[Releases のページ](../../releases/latest) から、次の 2 つを落とせます。

| ファイル | 中身 |

## 試す時

必要なものは、Windows 10 / 11 の PC と、Android 10 以上のスマホ、どちらもつながる Wi-Fi です。詳しい使い方は、ドキュメントの中の「SP Deck」（README）にあります。

1. PC で、インストーラーを実行します。
   - Windows が「PC が保護されました」と出した時は、「詳細情報」→「実行」で進みます（署名を付けていないためです）。
2. インストールが終わると、PC の画面右下（タスクトレイ）にアイコンが出て、QR コードの窓が開きます。
3. スマホの標準のカメラで QR コードを読み、開いたページから、スマホ用のアプリを入れます。
   - 「不明なアプリのインストール」の許可を求められたら、許可します。
   - Google Play プロテクトの確認が出た時は、折りたたまれている項目を開くと出てくる「インストールする」を押します。
4. 同じページの「アプリで開く」を押すと、つながります。

## 知っておいてほしいこと

- お試しの段階のものです。動作の保証はありません。
- 自宅の Wi-Fi で、1 人が、自分の PC とスマホで使うことを想定しています。
- スマホ用のアプリは、開発用の署名のものです。後で作り直したものに入れ替える時は、一度アンインストールが要ります。
- プログラム（ソース）は、公開していません。
- アプリに同梱している部品には、それぞれのライセンスがあります。一覧は、ドキュメントの中の「SP Deck に同梱している部品と、そのライセンス」と、インストール先の `licenses` フォルダにあります。
